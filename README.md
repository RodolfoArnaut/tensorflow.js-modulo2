# Pós Engenharia de IA Aplicada - UNIPDS

## Módulo 2: Fundamentos de IA e Redes Neurais - Análise de Perfil SaaS

Este projeto foi desenvolvido como parte das atividades do **Módulo 2** da Pós-Graduação em Engenharia de IA Aplicada da **UNIPDS**. Consiste em uma aplicação de análise de perfil de cliente utilizando **TensorFlow.js**, rodando diretamente no navegador do cliente.

### 🎯 Descrição
O projeto consiste em um **Analisador de Nível de Cliente (SaaS)** que utiliza processamento de redes neurais para:
1. **Classificação Automática**: Identifica se um cliente é *Basic*, *Medium* ou *Premium* baseando-se no volume de usuários, canais e uso de IA Generativa.
2. **Orçamento Dinâmico**: Calcula o custo mensal detalhado com base em regras de negócio (Canais, Usuários, Transcrição de Áudio e Integração ASAAS).
3. **IA no Navegador**: Demonstração prática de como integrar Inteligência Artificial diretamente no front-end para decisões instantâneas.

### 🚀 Tecnologias Utilizadas
- **TensorFlow.js**: Motor de Inteligência Artificial para treinamento e predição.
- **Javascript/HTML5**: Estrutura e lógica do sistema.
- **CSS3**: Design premium com efeitos de glassmorphism e dark mode.

### 🛠️ Como Executar
Basta abrir o arquivo `tensores/redes_neurais/exemplo-00-z/analisador.html` diretamente no seu navegador ou utilizar um servidor local como o `npx serve`.
